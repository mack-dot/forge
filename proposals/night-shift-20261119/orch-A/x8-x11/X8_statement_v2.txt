   NU(i) := #{ j | 27 <= j < i /\ ev_j = U }   (the count of NORMAL model steps before event i)

        !g. refund_strict_parse (STDOUT X) = SOME g ==>

      for Resource_limit_hit fd1_written io <<= render (refund_profile_a_sl_fd1, LO-0006); then STDOUT X <<= render
      and refund_frame_decision gives g = f_vals and STDOUT X = render. Exit status is NOT used.
 (C6) SCOPE (correction 4). X8 concludes NOTHING about a run X for which any premise in PREM fails. In particular a
      strict parse of STDOUT X is NOT evidence of correctness for such a run. v1 lines (d2) said that runs which
      leave A-FD1-WRITE are safe "because the frame parser is strict". That does not follow: after an unmodelled
