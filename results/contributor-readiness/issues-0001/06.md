Forge's ledger already proves that an identical retry returns `Ok` without repeating its effect (C3). Many services need exactly this, outside a ledger.

**Goal:** a small, reusable Dafny module (spec + implementation) for an idempotency-key store: same key and same request → same result, no second effect; same key and a different request → rejected. Plus a TypeScript wrapper checked with `tested_against_proved_model`, like `ts/ledger.ts`.

**Steps:** 1) open a proposal with the spec in plain English and in Dafny (new specs need approval); 2) after approval, add the implementation and evidence through the gate; 3) document how another project would reuse the spec, the implementation and the evidence.

**Done when:** the component has an approved spec, `source_proof` evidence for each claim, and a usage example. No `assume` or axioms.
