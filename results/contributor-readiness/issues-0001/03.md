When the gate rejects, the one readable line (for example `VERIFICATION_REJECTED: C4 not established; Dafny exit 4`) is printed last, after many raw Dafny JSON lines. New users miss it.

`gate/` is protected, so this starts as a proposal, not a code PR. See CONTRIBUTING.md, "Protected changes".

**Task:** write `proposals/gate-summary-first.md` with the exact diff that prints a one-line summary before the raw diagnostics (or a `--quiet` flag), a plain-English reason, and before/after output from real runs. The evidence bundle bytes must not change.

**Done when:** the proposal is ready for exact-byte approval and shows that `evidence.json` stays byte-identical.
