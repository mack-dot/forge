`toolchain/checksums.sha256` hard-codes paths such as `/opt/homebrew/Cellar/node/24.3.0/bin/node` and `/Library/Frameworks/Python.framework/.../python3.10`. It only passes on a host with exactly those files, and nothing explains how to install Node 24.3.0 or Python 3.10.11.

**Task:** document how to obtain the pinned Node and Python, and propose how to check executable digests per host profile without weakening the pins (pins in `toolchain/` are trust-critical, so describe the change in a proposal first).

**Done when:** a newcomer can tell which checks apply to their host and what to install.
