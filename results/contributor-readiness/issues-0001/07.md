`impl/Ledger.dfy` and `spec/LedgerSpec.dfy` prove C1–C5, but they are tied to this repository's layout and gate.

**Goal:** design a reusable package format for a proof-carrying component: the approved spec, its lock, the implementation, the evidence bundle and the exact command that reproduces the evidence. Another repository should be able to depend on a version and re-check it with the pinned checker, without trusting this repository's CI.

**Start with** a short design doc in `docs/`: what is packaged, how versions and hashes are bound, how a consumer re-checks, and what stays a trust assumption. No protected changes in the first PR.

**Done when:** the design doc is reviewed and names the open questions.
