# Project instructions

Read `ROADMAP.md` at the start of each run. Follow its operating mode and hard
rules. Work only on its CURRENT stage. A stage transition ends the run.

Read the relevant entries in `unsure.md` before resolving an uncertainty.
`unsure.md` is append-only. Never rewrite, delete, reorder, or modify an existing
entry. Add a new entry with a unique ID and references to prior IDs when a finding
changes or is resolved. Record evidence, uncertainty, impact, and the next check.
Do not turn a guess into a passing result.

Keep stage execution results in `ROADMAP.md`. Expected outcomes and commands
that have not run must remain clearly separate from actual exit codes.

Use ASD-STE100 as an approximately 80% guide. Use short sentences, active voice,
and consistent terminology. Relax vocabulary rules when needed for precision.

Keep the final response to at most 20 lines: current stage, EXIT command table
with actual exit codes, and blockers. No narrative.
